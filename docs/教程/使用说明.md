## 登录

打开站点根目录下的 `/admin/` 页面，点击 **Sign in with GitHub**，在 GitHub 授权页确认后即可登录，无需管理任何令牌。

> 技术说明：GitHub 登录（OAuth）需要一个中转服务器换取访问令牌。本站使用 Sveltia CMS 官方提供的 Cloudflare Worker 认证器（sveltia-cms-auth）承担此角色，Worker 本身免费托管，令牌只存于你的浏览器本地，不会经过第三方。

## 写文章

每个顶层文件夹对应一个文章类型。左侧选择文件夹，点「新建」，填写标题、日期和正文，保存即可。保存会自动产生一次 Git 提交。

## 发布

保存后的提交会触发 GitHub Actions，几分钟内站点自动更新。
