## 登录

打开站点根目录下的 `/admin/` 页面，选择 **Sign In with Token**，按提示创建一个 GitHub 个人访问令牌并粘贴进来（令牌保存在浏览器本地，只需创建一次）。

创建令牌时请注意（**这是登录报 "Not Found" 最常见的原因**）：

- 类型选择 **Tokens (classic)**，不要用 Fine-grained
- 权限勾选 **repo**
- 有效期建议选较长（如 90 天或无期限），到期后需重新生成

## 写文章

每个顶层文件夹对应一个文章类型。左侧选择文件夹，点「新建」，填写标题、日期和正文，保存即可。保存会自动产生一次 Git 提交。

## 发布

保存后的提交会触发 GitHub Actions，几分钟内站点自动更新。
